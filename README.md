Clear Score App

A simple score display application built with Swift and UIKit using the VIPER architecture pattern.
This project is created as a personal test project to practice iOS development concepts and clean architecture design.

Features

Display scores clearly to the user
Clean and simple UIKit interface
Structured using VIPER architecture
Lightweight and easy to maintain

Technologies Used
Swift
UIKit
VIPER Architecture

Architecture
The project follows the VIPER architecture pattern:

View — Handles UI elements and user interaction
Interactor — Contains business logic
Presenter — Connects the View and Interactor
Entity — Represents the data models
Router — Handles navigation

Purpose
This app is developed as a practice/test project to improve understanding of:
UIKit development
Swift programming
VIPER architecture
Clean code structure

How to Run
Clone the repository
Open the .xcodeproj or .xcworkspace file in Xcode
Build and run the project on a simulator or device
